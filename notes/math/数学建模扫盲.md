# 数学建模扫盲

## 基于20204年C题的建模

### 贪婪启发式

贪婪启发式 = 在构造解的每一步，按照预先设定的评价准则，选择当下收益最大的选项，逐步搭建完整方案

贪婪算法

每一步**只看当前局部最优**，不考虑长远、不回头、不预判未来损失

启发式

不是精确算法，**不保证算出全局最优解**，目标是快速找到一个质量不错的可行解



适合场景

- 大模型组合优化， 变量极多/动态规划求解超时
- 快速求出可行性方案，实时调度，在线决策
- 需要生成初始值，作为其他算法，如局部搜索的起点

**不直接求解方程组**，是一套**构造规则、计算流程**，用来快速生成可行解



### 机会约束规划CPP

传统模型：普通线性规划 / 整数规划 约束固定

机会约束思想：不要求约束每时每刻都成立，允许小概率违反约束，我们只控制违规概率不超过预设风险上限

设定一个超限的阈值 风险容忍水平



前提：

- **模型存在随机参数**（产量、需求、价格、成本等不是固定常数，具备随机性）；

- **完全严格满足约束过于保守 / 不现实**，可以接受小概率违规；

- **能够刻画随机变量分布**（正态分布、对数正态等，你文中假设正态分布）；

- **风险可以明确定义**：能写出 “哪些情况属于违规事件”；

- 目标一般优化**期望收益 / 期望成本**



### 蒙特卡洛模拟

当模型里有一大堆随机变量（产量、价格、需求、成本），没办法直接算出利润精确分布时，我们靠「大量随机抽样仿真」，用大量样本去近似真实概率分布。

eg：

想知道一个骰子掷出点数的分布，不用数学推导，连续掷骰子 300 次，统计每种点数出现多少次，这就是最简单的蒙特卡洛

决策变量 = **CCP 模型求出的最优种植方案（固定不变）**

不确定量 = 每年作物产量、售价、需求量、种植成本（全部是随机变量，服从正态 / 给定分布）

目标：

固定种植方案，反复随机生成市场与产出情景，算出每一轮情景下 7 年总利润，最后得到**总利润的概率分布**，用来评估方案稳不稳定、风险多大。



用机会约束规划CPP 得到一套最佳的方案  再用蒙特卡洛去随机模拟不同的情况（不确定性），最后给出随即环境下的收益期望和概率



### 系统动力学

研究 动态反馈系统的仿真建模  变量之间的动态关系

普通优化模型（整数规划、机会约束 CCP）特点：

> 大多是**静态 / 分期独立决策**，假设变量之间只有简单约束，很难刻画「变量互相影响、不断动态循环」。

系统动力学：现实是一张互相缠绕的因果网络，一个变量变化，沿着链条一圈一圈反过来影响自身，形成**反馈回路**，长期演化出动态行为（增长、震荡、收敛）



#### R 增强贿赂

正反馈	同向不断放大，越涨越涨 / 越跌越跌

#### B 平衡回路

起到抑制、调节、缓冲作用，阻止无限增长，趋向平衡



系统动力学作用

- 刻画变量之间双向动态反馈关系
- 模拟长期时间演化动态趋势
- 直观表达复杂系统内部机理
- 情景仿真、政策试验

使用前提： 反馈闭环的动态系统，关注中长期的演变行为，存在延迟效应，系统的复杂性。
